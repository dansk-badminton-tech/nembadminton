# Help targets search-engine discovery via a sitemap

ADR 0002 accepted that Help would not target search-engine discovery. We now want coaches who search for holdturnering problems to land on our User Guides, so Laravel serves a `/sitemap.xml` that lists every public Help route, derived from the Help Markdown files so new User Guides and Release Announcements appear without manual upkeep, and `robots.txt` points to it. Help stays client-rendered in the existing Vue application; we rely on search engines rendering JavaScript, and per-page titles, descriptions and server-side rendering are deliberately left for a later decision. The sitemap is a Laravel route rather than a build artifact because the Simply deploy ships only `public/build`, so a file generated into `public/` at build time would never reach production.
