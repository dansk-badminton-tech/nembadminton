# Public Help in the existing Vue application

NemBadminton keeps public User Guides, Release Announcements, FAQ, and About content as source-controlled Markdown rendered by a dedicated public layout in the existing Vue application and router. This keeps documentation reviewable and deployable with each feature while avoiding the operational cost of a CMS, external documentation site, or second frontend build; the trade-off is that the initial Help area is client-rendered and does not target search-engine discovery.
