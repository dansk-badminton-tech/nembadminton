# Nembadminton Branding

## Name

The platform's name is **Nembadminton**.

Use `Nembadminton` in all human-readable communication, including user interfaces, browser titles, emails, legal text, help content, documentation, and code comments.

Do not use `NemBadminton` or lowercase `nembadminton` when referring to the platform by name.

### Possessive forms

- In Danish, use `Nembadmintons` without an apostrophe.
- In English, use `Nembadminton's`.

### Technical identifiers

Keep technical identifiers in their existing form. This includes variables, properties, classes, package names, repository names, filesystem paths, configuration keys, hostnames, and email addresses.

The domain name is always lowercase: `nembadminton.dk`. Keep it lowercase even at the beginning of a sentence or in a page title.

Examples:

- `Log ind på Nembadminton via nembadminton.dk.`
- `Læs mere om Nembadmintons funktioner.`
- `Contact Nembadminton's support team at info@nembadminton.dk.`
